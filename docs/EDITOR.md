# Как обновлять сайт

Меняйте файлы данных через GitHub (кнопка редактирования файла) или локально. После сохранения в `main` GitHub Actions проверит данные, соберёт сайт, запустит тесты и опубликует успешную сборку. Ошибка проверки останавливает deploy.

## Новости

Файл `src/data/news.json` содержит массив публикаций. Добавьте объект со следующими полями. Значения ниже — **пример структуры, не реальная новость**; замените все поля проверенными сведениями, не публикуйте пример как событие федерации.

```json
{
  "id": "unique-news-id",
  "title": "Заголовок подтверждённой публикации",
  "date": "2026-10-14",
  "category": "Соревнования",
  "summary": "Краткое содержание, проверенное по первоисточнику.",
  "sourceUrl": "https://АДРЕС-ПЕРВОИСТОЧНИКА"
}
```

Дата — дата реальной публикации в формате `YYYY-MM-DD`. Новости сортируются от новых к старым; категории создают фильтры автоматически. Для статьи с фото добавьте `image`, `imageAlt` и `mediaId`; изображение должно совпадать с разрешённой записью в `media.json`. Без фото публикация имеет текстовую композицию. Тематические фото международных стартов не подставляйте как фото конкретной новости Пскова.

## События

В `src/data/events.json` добавляются объекты с `id`, `title`, `date`, необязательным `endDate`, `location`, `summary`, `sourceUrl`. Формат дат такой же. Если событие длится несколько дней, `endDate` должен быть не раньше `date`. События автоматически делятся на прошедшие и предстоящие по текущей дате в часовом поясе Москвы. Дата окончательного завершения определяет статус многодневного события. В описании прошлых событий можно указать только проверенные результаты.

## Фотографии и видео

1. Получите разрешение правообладателя на повторную публикацию. Либо выберите фото с подходящей открытой лицензией, соблюдайте её условия. Для фотографий несовершеннолетних подтвердите необходимые согласия. Публичность VK сама по себе не даёт разрешения.
2. Сохраните подтверждения в закрытом реестре федерации. Не помещайте подписанные согласия с личными данными в публичный репозиторий.
3. Оптимизируйте фото в WebP/AVIF, обычно до 1600 px по длинной стороне. Дайте файлу осмысленное имя; загрузите его в `public/images/`.
4. Добавьте запись в `src/data/media.json`:

```json
{
  "id": "unique-media-id",
  "type": "image",
  "src": "images/ИМЯ-ФАЙЛА.webp",
  "width": 1600,
  "height": 1067,
  "variants": [{"src": "images/ИМЯ-ФАЙЛА-640.webp", "width": 640}, {"src": "images/ИМЯ-ФАЙЛА.webp", "width": 1600}],
  "alt": "Краткое содержательное описание кадра",
  "caption": "Проверенное событие и место съёмки",
  "sourceUrl": "https://АДРЕС-ПЕРВОИСТОЧНИКА",
  "author": "Имя автора",
  "license": "CC BY 4.0",
  "licenseUrl": "https://creativecommons.org/licenses/by/4.0/",
  "changes": "Уменьшение, WebP; адаптивный кроп.",
  "permissionStatus": "approved",
  "minorsPermission": "not-applicable",
  "weapon": "epee",
  "weaponVerification": "Как установлено, что на кадре именно шпага",
  "rightsReference": "Ссылка на лицензию либо номер записи закрытого реестра разрешений"
}
```

`not-applicable` допустимо только если согласие для изображения несовершеннолетних не требуется. Если на кадре есть дети, публикуйте только после необходимого подтверждения и укажите `minorsPermission: "approved"`. Флаги — запись результата реальной проверки, а не способ её обойти. У свободных материалов укажите точное название лицензии, автора и ссылку на оригинал.

Видео: `type: "video"`, локальный `src`, обязательный `poster` и остальные сведения об авторстве и правах. Видео имеет элементы управления, не запускается со звуком автоматически и не загружается целиком до воспроизведения. Фото в галерее открываются в диалоге, закрываются кнопкой и Escape.

Портрет тренера добавляется через `photo` в `src/data/federation.json`; соответствующая запись о разрешении должна существовать в `media.json`. После добавления фото проверьте кадрирование на мобильном устройстве. Не используйте фотографию другого спортсмена вместо портрета тренера.

## Контакты и источники

Контакты, адрес тренировочного зала, сведения о руководстве и тренерах — `src/data/federation.json`. Юридический адрес не подставляйте вместо адреса занятий. Стаж указан вместе с оговоркой о дате отсчёта; обновляйте его только после подтверждения.

Для каждого значимого факта добавляйте или обновляйте запись в `src/data/sources.json`: источник, ссылка, статус проверки и примечание. Статус `verified` ставится после реальной сверки. Наименование `sourceId` в данных должно ссылаться на существующий источник.

## Перед сохранением

Выполните `npm run build` и `npm test`. Проверьте даты и контакты, права на фото, мобильное кадрирование, первоисточники и страницу `/sources/`. Для официального представления нужна отдельная финальная проверка руководителем; публикация на Pages не заменяет согласование.


## Будущие модели Blender

См. `docs/3D-INTEGRATION.md`. Не включайте модель до получения файла и согласованного фотопостера. Не создавайте временные модели. Фото и видео должны быть уверенно отнесены к шпажному фехтованию, а не определяться по белой форме.

## Фотосцены и проверка опубликованного сайта

`src/motion.ts` управляет параллаксом hero и закреплённым поединком; геометрия измеряется при загрузке/изменении размеров, обработчик прокрутки обновляет CSS transforms. Раскрытие фото — IntersectionObserver; фотолента — нативный scroll-snap и кнопки. При reduced-motion обе главы видны статично.

`node scripts/capture-site.mjs` проверяет 11 маршрутов, изображения, консоль и семь ширин, затем записывает прокрутку 1440×900 и 390×844. `SITE_URL` задаёт адрес, `CAPTURE_OUTPUT` — каталог. Проверка TLS включена. После deploy workflow запускает этот скрипт на публичном Pages и сохраняет артефакт `published-visual-review` на 30 дней. Запись видео — QA-материал, не видео на самом сайте.
