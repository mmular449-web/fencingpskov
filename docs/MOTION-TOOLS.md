# Motion и навыки Codex — установка 15.10.2026

## Установлено

| Инструмент | Версия / расположение | Статус |
| --- | --- | --- |

В проекте до работы не было Motion или этих навыков. React, GSAP и платные пакеты не добавлялись. `framer-motion` — обязательная транзитивная зависимость официального пакета `motion`, прямых импортов или отдельной установки нет; React/ReactDOM отсутствуют. CLI установщиков находятся вне зависимостей сайта и не входят в бандл.

Three.js, `@types/three`, загрузчик, конфигурация моделей, проверка моделей при сборке, подготовленные заглушки и инструкция подключения удалены по последнему требованию владельца. Предметный блок использует существующую разрешённую фотографию. Blender-репозиторий не изменялся.

## Проверка установщиков и лицензий

До запуска прочитаны README, package manifests, лицензии, исходники CLI `skills@1.7.2`, `motion-ai@14.2.0` и его механизма записи MCP (`add-mcp@2.4.1`). Архивы получены через `npm pack`, установка CLI — с `--ignore-scripts`. Телеметрия skills отключена `DISABLE_TELEMETRY=1 DO_NOT_TRACK=1`; никаких shell-installers из интернета не запускалось. После установки все 21 файла community skill совпали с проверенным исходником по SHA-256.

- Motion/runtime-зависимости — MIT; тексты в `public/licenses/motion-MIT.txt`.
- Community skill — MIT, его `LICENSE` сохранён рядом с навыком.
- CLI skills — MIT; add-mcp — Apache-2.0.
- `motion-ai` декларирует MIT в опубликованном `package.json`. В проверенном ai-kit репозитории отдельного текста LICENSE нет; это различие зафиксировано, дополнительная лицензия не придумана. Сохранены метаданные происхождения и исходное содержимое навыка.
- [Версии, Git SHA, integrity npm-архивов и результат обнаружения](qa/motion-tools.json).

Команды использовали предварительно проверенные локальные CLI, чтобы `npx` не скачивал и не запускал произвольную новую версию:

```sh
# после подготовки проверенных CLI вне проекта
DISABLE_TELEMETRY=1 DO_NOT_TRACK=1 npx --no-install --prefix /tmp/motion-tools-audit/cli skills add https://github.com/199-biotechnologies/motion-dev-animations-skill -a codex --skill motion-dev-animations --copy -y
npx --no-install --prefix /tmp/motion-tools-audit/cli motion-ai
npm install --save-exact --ignore-scripts motion@14.2.0
```

Повторять установку не нужно: навыки и конфигурация сохранены в репозитории, runtime восстанавливается обычным `npm ci` из lockfile.

## Обнаружение и ограничения MCP

`skills list -a codex --json` обнаруживает оба навыка. Дополнительно проверен **реальный Codex backend 0.159.2**, запросом `skills/list` с `forceReload: true` через app-server: `motion` и `motion-dev-animations` имеют `scope: repo`, `enabled: true`, ошибок сканирования нет. Это проверка метаданных, без запуска другого агента. Каталог инструментов уже идущей беседы не обновился; для автоматического подключения навыков в каталоге текущей сессии следует начать новую сессию Codex в этом проекте. Сейчас файлы навыков прочитаны напрямую.

Проектная `.codex/config.toml` записана официальным установщиком и приведена к native-синтаксису Codex (`url`, без лишнего `type`). Формат endpoint проверен командой `codex -c 'mcp_servers.motion.url="https://mcp.motion.dev"' mcp get motion`. Однако текущий управляемый CLI не подхватывает проектный MCP автоматически: обычный `codex mcp get motion` его не показывает. Глобальные настройки доверия не изменялись. Не следует считать MCP подключённым, пока новая доверенная сессия не загрузит конфигурацию.

Дополнительный блокер — HTTPS endpoint `https://mcp.motion.dev` получает **403 от сетевого прокси** этой среды. Домен добавлен с сохранением всех прежних правил в черновик сети; черновик сохранён, но не применён. Для применения нужно сохранить настройки среды и опубликовать её. Поиск документации через MCP и MotionScore не проверены и не объявляются работающими. Motion+ отключён; вход, покупка и установка платных пакетов не выполнялись.

Встроенные `best-practices/` официального навыка работают без сервера. Они применены к vanilla TypeScript: `motion/mini`, scroll/inView, transform/opacity, CSS для простых состояний, отмена эффектов и reduced-motion. Community skill в основном ориентирован на React и используется как справочник, без смены стека. Официальная справка: https://motion.dev/docs/ai-kit .
