# Визуальная проверка Motion / 2D

Скриншоты и прямые WebM в `../videos/` обновлены 15.10.2026 по финальной production-сборке коммита `281b932`: desktop 1440×900 и mobile 390×844. Непрерывная прокрутка записана через Chromium CDP и доверенный системный FFmpeg, 25 fps; длительности 37.64 / 36.68 с. Обе записи осмотрены по кадрам. Все 50 файлов этой сборки совпали по SHA-256 с публичными HTTPS-ресурсами GitHub Pages: `../qa/public-files.json`.

Дополнительно вручную осмотрены 375×812, 430×932, обе главы поединка, touch-галерея и reduced-motion. Результат профилирования с CPU ×4 — `../qa/motion-runtime.json`. Эмуляция Chromium не заменяет физический iPhone/Safari.

Отдельная проверка **самого публичного адреса** выполнена Chromium в GitHub Actions без отключения TLS: 11 маршрутов, семь ширин, декодирование изображений и отсутствие ошибок консоли. Там же записаны две публичные прокрутки и 22 скриншота: https://github.com/mmular449-web/fencingpskov/actions/runs/38749842864/artifacts/11980492307 . Срок хранения 30 дней.

Прямые локальные файлы не выдаются за скачанные кадры CI. Ранее скачивание CI-артефактов в эту среду блокировалось сетевым прокси (403 для productionresultssa5.blob.core.windows.net). Сетевые изменения ещё не применены, повторная загрузка не выполнялась. Происхождение локальных записей — `../qa/motion-capture-origin.json`.
