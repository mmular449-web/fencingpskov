# Визуальная проверка

Скриншоты и прямые WebM в `../videos/` сняты в Chromium на production-копии: 1440×900 и 390×844. Все 52 файла этой сборки совпали по SHA-256 с опубликованными HTTPS-ресурсами GitHub Pages. Дополнительно вручную просмотрены 375×812, 430×932 и reduced-motion.

Отдельная проверка **самого публичного адреса** выполнена Chromium в GitHub Actions без отключения TLS: 11 маршрутов, семь ширин, все изображения и отсутствие ошибок консоли. Там же записаны обе публичные прокрутки и 22 скриншота: https://github.com/mmular449-web/fencingpskov/actions/runs/38722147875/artifacts/11967066992 .

Скачать этот артефакт обратно в облачную среду не удалось: её прокси блокирует `productionresultssa5.blob.core.windows.net` (403). Поэтому файлы здесь не выдаются за скачанные кадры CI. Сетевой черновик дополнен, но ещё не применён пользователем. Результаты CI и публичные байты проверены независимо.

`comparison-*.png` показывает первый экран до и после изменения. Исходная версия — коммит `12e6735`, новая production-версия — `d0112f3`.
