# Фотография и Motion

Проект использует Vanilla TypeScript. Runtime: `motion@14.2.0`, без React. Импорты `animate` из `motion/mini`, `scroll` / `inView` из `motion`. Простые hover/focus/press остаются в CSS. 3D полностью исключено, моделей и просмотрщиков нет.

## Режиссура сцен

- Hero: последовательный вход текста, появление фотографии, разные скорости движения фото и текстового слоя. CTA остаются на месте и доступны во время анимации.
- Поединок: CSS sticky, привязанное к прокрутке масштабирование 1.12 → 1, движение заголовка и прогресс. На 52% диапазона меняется смысловая глава через короткий кроссфейд. При обратной прокрутке переход продолжается от текущих значений, без резкого сброса.
- Предметный кадр и остальные фото: однократное раскрытие маской и масштабом после `img.decode()`. Текст и новости появляются с небольшим интервалом.
- Фотолента: нативная touch-прокрутка и scroll-snap, стрелки, счётчик и управление с клавиатуры.
- Галерея: следующий кадр предварительно декодируется; две фотографии переходят друг в друга за 320–400 мс. Стрелки, свайпы и клавиши работают одинаково; Escape закрывает диалог и возвращает фокус.

## Настройка и жизненный цикл

`src/motion.ts`: диапазоны `offset`, масштабы, смещения, порог главы и длительности. `refresh(scope)` подключает новые публикации после фильтрации. `dispose()` снимает наблюдателей, таймеры, scroll-связи и анимации, восстанавливает стили. После возврата из browser back/forward cache инициализация повторяется.

Motion выбирает native ViewTimeline/ScrollTimeline, когда браузер и диапазон это позволяют, иначе использует JS fallback. При завершении сначала отменяется анимация, затем снимается scroll-связь: это предотвращает `commitStyles` на уже скрытом reduced-motion элементе. Измерения для главы происходят только при переключении главы, а не каждый кадр.

`src/gallery.ts`: отдельный жизненный цикл фотодиалога; токен поколения отменяет устаревшие асинхронные переходы. Ошибка загрузки оставляет предыдущий кадр. Новые медиа берутся из `src/data/media.json` только после проверки прав.

`src/style.css`: sticky-композиция, мобильное кадрирование, CSS-состояния кнопок и полноценная статичная reduced-motion раскладка. Не добавляйте постоянный `will-change` всем элементам.

## Доступность и проверка

`prefers-reduced-motion` отслеживается и при загрузке, и при изменении настройки: движение отменяется, обе главы доступны в обычном потоке, галерея меняет кадр сразу. Неактивная глава в обычном режиме имеет `inert` и `aria-hidden`. Клавиатурный фокус завершает reveal своего блока.

`npm run build && npm test`: маршруты, ссылки, доступность, семь ширин, галерея и свайпы, изменение reduced-motion, resize, scroll fallback с отключёнными native timeline API. Lighthouse запускается отдельно от других браузерных нагрузок. Визуальные записи: `scripts/record-local.mjs` локально, `scripts/capture-site.mjs` в CI на публичном адресе.

Видео на сайт не добавлено: подходящего проверенного материала с достаточным качеством и правами пока нет. Не подставляйте непроверенный ролик ради эффекта.
