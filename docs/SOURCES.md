## Фотографии и проверка оружия

**В новой публичной версии нет фотографий, происхождение и права на которые не удалось подтвердить.** Разрешённых фотографий пока 0; `src/data/media.json` пуст. Для hero выбрана законченная типографическая композиция. Портреты тренеров заменены текстовым представлением, без монограмм и искусственных лиц.

Предприняты попытки:

- VK: `https://vk.ru/fehtovanie_pskov` и `https://vk.com/fehtovanie_pskov` — доступ блокируется прокси (403).
- Старый сайт федерации открыт; ссылки на фото и альбомы найдены. Фотосерверы `i.siteapi.org` / `s2.siteapi.org` недоступны из среды. Кадры не осмотрены; тип оружия и лица на них не утверждаются. Право на повторную публикацию и согласия на фотографии детей также не подтверждены.
- Wikimedia Commons: API и поиск возвращают 403. Доступная категория `Épée` относится к историческому оружию и не даёт подходящего материала для спортивной шпаги. Такой материал отвергнут.
- Сентябрьская публикация федерации включает совместную тренировку с рапиристками. Её фотографии не отбирались для шпажного сайта.

Никакие сомнительные изображения не загружены в публичный каталог. На странице галереи доступны первоисточники, а не имитация фотогалереи.

Для будущего кадра обязательны: уверенное определение шпаги по чашеобразной гарде/конструкции либо надёжному контексту события; автор, лицензия или разрешение; необходимые согласия, если есть несовершеннолетние. Белая экипировка не является доказательством типа оружия. Проверка сборки требует `weapon: "epee"`, описание `weaponVerification` и `rightsReference`.

## Оформление и лицензии

- Прежние рисунки шпаги, маски и дорожки удалены из публичных файлов и компонентов.
- Обложка ссылок и favicon — собственное типографическое оформление без изображения оружия.
- Шрифт Golos Text поставляется локально через Fontsource, SIL OFL 1.1; лицензия в `public/licenses/golos-text-OFL.txt`.
- 3D-модели не создавались. Three.js — MIT, отложенный модуль для будущих файлов Blender. Их лицензии и права на текстуры будут проверены при получении.
- Общие сведения о правилах шпаги имеют ссылку на FIE: https://fie.org/fie/documents/rules . Это вводное объяснение, не регламент соревнования.

Реестр источников в данных: `src/data/sources.json`; публичная версия: `/sources/`.
