# Реестр фактов и изображений

Полный реестр доступен в `src/data/sources.json` и на странице сайта `/sources/`.

## Факты

| Сведения | Исходный источник | Проверка |
| --- | --- | --- |
| Название федерации, специализация | Задание владельца | Независимая сверка ожидается |
| Набор 7–14 лет, школа «Лидер» | Задание владельца | Подтвердить текущий набор |
| Тренеры, спортивные звания, категория, стаж и телефоны | Задание владельца | Подтвердить актуальность; стаж не увеличивается автоматически |
| Президент Муляр Александр Владимирович | Задание владельца | Подтвердить текущую должность |
| Зал: Псков, Кузнецкая, 25, стадион «Машиностроитель» | Задание владельца | Подтвердить адрес занятий; юридический адрес не заявлен |
| Общие правила шпаги, дорожка 14 м, типовые взрослые форматы | Общие сведения о спортивном фехтовании; ссылка FIE для сверки | Не заменяют актуальные правила и регламент; требуется сверка официального текста |
| История, новости, награды и результаты | Источники недоступны | Конкретные исторические сведения, публикации и результаты не добавлены |

Попытки чтения: `vk.ru/fehtovanie_pskov`, `vk.com/fehtovanie_pskov`, `fencingpskov.nethouse.ru/`, `/about`, `/articles`, `www.rusfencing.ru/fed_card.php?ID=607`, `org_card.php?ID=202546`, `www.apple.com/`. Все вернули ошибку сетевого туннеля 403, а не содержимое страницы. Это ограничение среды, не вывод о доступности сайтов для обычного посетителя. Wikimedia также недоступна из исходной среды; свободные фотографии не получены. Альтернативный домен VK проверен, авторизация и технические ограничения не обходились.

Фотографии спортсменов, детей и тренеров не опубликованы. Реестр одобренных фото/видео `media.json` пуст. Для каждого будущего файла нужны источник, автор, основание публикации и необходимые разрешения.

Дополнительно проверен доступ к https://fie.org/fie/documents/rules — также ошибка туннеля 403. Домен `fie.org` добавлен в сетевой черновик среды для будущей сверки. Сохранение черновика не применяет правила к текущей среде.
