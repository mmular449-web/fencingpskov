## Навыки и сеть

У текущей беседы каталог навыков не обновился; для автоматического обнаружения в каталоге следует начать новую сессию Codex в проекте. Сейчас навыки прочитаны напрямую. Официальные offline best-practices применены.

`.codex/config.toml` подготовлен официальным установщиком. Free Motion MCP недоступен: прокси возвращает 403; текущий управляемый CLI также не подхватывает проектную MCP-конфигурацию автоматически. Motion+ отключён, платные пакеты/вход не использованы. Домен `mcp.motion.dev` добавлен к сохранённому сетевому черновику без удаления прежних правил. Черновик не применён: настройки нужно сохранить и опубликовать среду. Не повторять сетевые попытки до изменения настроек и не обходить прокси/TLS.

## Продолжение

Прочитать `AGENTS.md`, `docs/MOTION-TOOLS.md`, `docs/ANIMATION.md`, `docs/DELIVERY.md`. `npm ci` восстанавливает Motion; повторно ставить навыки не нужно. Проверки: `npm run build && npm test`, отдельный Lighthouse и визуальная проверка. Публикация — push в main, успешные build/deploy/verify-public, затем проверка реальных ресурсов Pages.

Фотографии федерации/детей, портреты и качественное видео ожидают подтверждённых прав и необходимых согласий. Физический iPhone недоступен; эмуляция Chromium не заменяет Safari на устройстве. Набор, контакты/стаж, документы и официальный статус требуют финального согласования руководителем.
