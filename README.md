# Фехтование Псков

Фотографическая презентация Федерации фехтования Псковской области: крупные спортивные кадры, контрастные секции, Motion-анимации и 11 отдельных страниц. **Версия для согласования руководством.**

Сайт: https://mmular449-web.github.io/fencingpskov/

## Разработка

Node.js 24+, TypeScript, Vite. Используйте существующий checkout, отдельный worktree не нужен.

```sh
cd /workspace/fencingpskov
NPM_CONFIG_CACHE=/workspace/.npm-cache npm ci
npm run dev -- --port 5173 --strictPort
```

Базовый путь — `/fencingpskov/`. Каждая страница имеет отдельный `index.html`; прямые переходы и обновление работают на GitHub Pages без SPA-редиректов.

```sh
npm run build
npm test
npm run preview -- --port 4173 --strictPort
CHROME_PATH=/usr/bin/chromium npm run audit
```

Для тестов используется системный `/usr/bin/chromium`, если он доступен вне CI. На другой машине: `npx playwright install chromium` или `CHROMIUM_PATH`. В CI браузер устанавливается официальной командой Playwright.

## Архитектура

`src/main.ts` — страницы и взаимодействия; `src/style.css` — дизайн-система; `src/data/` — редактируемое содержимое. История, три новости и два архивных события сверены с источниками. Галерея содержит пять проверенных фотографий взрослых международных шпажных стартов и оборудования по открытым лицензиям. Кадры не выдаются за мероприятия федерации. `src/motion.ts` — фотосцены, параллакс, scroll zoom и доступная фотолента.

`src/gallery.ts` — доступный фотодиалог с декодированием следующего кадра, Motion-кроссфейдом, свайпами и клавиатурой. `src/components/equipment.ts` — предметная фотография реальных шпаг. Проект использует только 2D: Three.js, просмотрщик, конфигурация и заглушки моделей удалены.

Сборка проверяет типы, содержимое, разрешения медиа и пути файлов. Motion закреплён в lockfile; React и платные компоненты не устанавливаются. Навыки Codex сохранены в `.agents/skills/` и не попадают в публичную сборку.

## Публикация

Workflow `.github/workflows/pages.yml` после push в `main` устанавливает зависимости из lockfile, собирает, запускает браузерные тесты и публикует только успешную сборку. Source в Settings → Pages — GitHub Actions. Actions закреплены на SHA. После deploy обычный Chromium проверяет публичные страницы, семь ширин и записывает видео прокрутки desktop/mobile; артефакт `published-visual-review` доступен в Actions 30 дней.

При будущем собственном домене обновляются DNS, base path, canonical, Open Graph и sitemap. Текущий адрес использует `/fencingpskov/`. Ресурсы имеют хэши в именах; HTTP-кэширование GitHub Pages управляется платформой.

## Согласование

Нет разрешённых фото федерации, поэтому сомнительные материалы не публикуются. Требуются подтверждение актуального набора, контактов, звания/стажа, условий занятий, документов и итогового статуса официального сайта. Техническая публикация не заменяет согласование.
