# Фехтование Псков

Редизайн сайта Федерации фехтования Псковской области. Сдержанная графитовая палитра, крупная типографика, округлые CTA, контрастные секции, 11 отдельных страниц и инфраструктура для будущих моделей Blender. **Версия для согласования руководством.**

Сайт: https://mmular449-web.github.io/fencingpskov/

## Разработка

Node.js 24+, TypeScript, Vite. Используйте существующий checkout, отдельный worktree не нужен.

```sh
cd /workspace/fencingpskov
NPM_CONFIG_CACHE=/workspace/.npm-cache npm ci
npm run dev -- --port 5173 --strictPort
```

Базовый путь — `/fencingpskov/`. Каждая страница имеет отдельный `index.html`; прямые переходы и обновление работают на GitHub Pages без SPA-редиректов.

```sh
npm run build
npm test
npm run preview -- --port 4173 --strictPort
CHROME_PATH=/usr/bin/chromium npm run audit
```

Для тестов используется системный `/usr/bin/chromium`, если он доступен вне CI. На другой машине: `npx playwright install chromium` или `CHROMIUM_PATH`. В CI браузер устанавливается официальной командой Playwright.

## Архитектура

`src/main.ts` — страницы и взаимодействия; `src/style.css` — дизайн-система; `src/data/` — редактируемое содержимое. История, три новости и два архивных события сверены с источниками. Галерея работает с одобренными материалами; пока таких фото нет, показывается композиция со ссылками на фотоархив, без пустых карточек.

`src/three/` содержит переиспользуемый GLB-просмотрщик. **Обе модели отключены**, пути файлов `null`. Three.js и GLTFLoader находятся в отдельном динамическом чанке и не загружаются текущими страницами. Временных моделей и заменителей нет.

Сборка проверяет типы, содержимое, разрешения медиа и параметры 3D. Включение модели без файла и согласованного постера запрещено проверкой. Примерные камеры не считаются проверенными до получения настоящих GLB.

## Публикация

Workflow `.github/workflows/pages.yml` после push в `main` устанавливает зависимости из lockfile, собирает, запускает браузерные тесты и публикует только успешную сборку. Source в Settings → Pages — GitHub Actions. Actions закреплены на SHA.

При будущем собственном домене обновляются DNS, base path, canonical, Open Graph и sitemap. Текущий адрес использует `/fencingpskov/`. Ресурсы имеют хэши в именах; HTTP-кэширование GitHub Pages управляется платформой.
