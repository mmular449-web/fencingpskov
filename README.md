# Фехтование Псков

Сайт Федерации фехтования Псковской области: 11 страниц, TypeScript, Vite, локальные шрифты и статическая публикация на GitHub Pages. **Версия для согласования, не утверждённый официальный сайт.**

## Разработка

Нужен Node.js 24 и npm. В облачной задаче используйте существующий checkout `/workspace/fencingpskov`; отдельный worktree не нужен.

```sh
cd /workspace/fencingpskov
NPM_CONFIG_CACHE=/workspace/.npm-cache npm ci
npm run dev -- --port 5173 --strictPort
```

Vite использует `/fencingpskov/` как базовый путь. Команды для проверки:

```sh
npm run build
npm test
npm run preview -- --port 4173 --strictPort
```

Тесты используют установленный `/usr/bin/chromium`, если он доступен вне CI. На другой машине выполните `npx playwright install chromium`; можно задать `CHROMIUM_PATH`. На Linux для установки системных библиотек Playwright используйте официальную команду `npx playwright install --with-deps chromium`.

## Структура

- `src/main.ts` — компоненты и логика страниц.
- `src/style.css` — адаптивное оформление.
- `src/data/` — содержимое, независимое от компонентов.
- `public/images/` — локальные иллюстрации и согласованные медиа.
- `public/licenses/` — лицензии локальных шрифтов.
- `scripts/validate-content.mjs` — проверка дат, ссылок, медиа и источников перед сборкой.
- `tests/site.spec.ts` — проверки страниц, клавиатуры, мобильного интерфейса и axe.
- `docs/EDITOR.md` — инструкция по добавлению новостей, событий и фото.
- `docs/SOURCES.md` — реестр фактов и прав на изображения.
- `PROGRESS.md` — сделанное, блокеры и следующий этап.

В каждой директории страницы есть `index.html`, поэтому прямое открытие и обновление работают на GitHub Pages без перенаправлений SPA.

## Публикация

Workflow `.github/workflows/pages.yml` запускается после push в `main`: `npm ci`, сборка, браузерные проверки и затем deploy. Сторонние Actions закреплены на проверенных SHA.

В настройках этого репозитория **Settings → Pages → Source: GitHub Actions**. Сайт опубликован: https://mmular449-web.github.io/fencingpskov/ . Build и deploy подтверждены успешным run, публичные HTTPS-ответы и 40 файлов проверены; подробности и ограничение прямого браузерного прогона через прокси — в `PROGRESS.md`.

## Статус материалов

Сведения о тренерах, наборе и руководстве взяты из задания владельца и требуют актуального подтверждения. Запросы к VK, Nethouse и ФФР из исходной среды блокировались сетевой политикой. Проверенных публикаций, соревнований и разрешённых фотографий поэтому пока нет; массивы данных пусты намеренно. Разделы дают честное объяснение и ссылки на первоисточники.

Вместо чужих фотографий используются собственные SVG шпаги, маски и дорожки. Настоящие портреты и фотографии несовершеннолетних не публикуются без необходимых разрешений. Перед представлением сайта как официального согласуйте материалы и статус с руководителем.
